Privacy

What this site reads, what it keeps, and how to have it removed. It is short because the site keeps very little.

What it reads about you

When you enter a handle, this site asks the public Codeforces API for that account’s submissions and rating changes — the same data anybody can see on the profile page. It never sees a password, and there is nothing to log in to. It cannot read anything private, and it never submits, runs or judges code.

What it keeps

A copy of those public submissions, so that reloading a page does not fetch them again. Anything older than {{ fresh_minutes }} minutes is fetched fresh.

And one row for each page you open, holding four things: the handle you looked up if there was one, which page it was, the time, and a random identifier from a cookie this site sets.

That is the whole list. No IP address, no browser or device details, no referrer, no accounts, no passwords. Nothing here is shared with anybody, sold, or sent anywhere else, and no page on this site loads anything from another company’s server — no analytics, no fonts from a CDN, no trackers of any kind.

The cookie

One cookie, called {{ cookie_name }}. It holds a random string generated when you first arrive; it is not derived from anything about you, and it means nothing anywhere else on the internet. It lasts {{ cookie_days }} days and is used for exactly one thing: counting how many different people have used this site and how many came back.

If you refuse it, everything works the same. You are then counted as a new person on each visit, which makes one of the numbers below less accurate and costs you nothing.

Why any of it is kept

This project claims its recommendations are measured rather than guessed, and it holds itself to three tests before calling version 1.0 done. One of them is that at least 50 people other than the author have used it and 20 have come back. That claim needs counting, and a visit that was not written down cannot be counted later. The counting is of people, not of what any one person did.

Having it removed

Ask, and the rows for a handle are deleted. Open an issue at the project’s repository; naming the handle is enough, and there is nothing else to identify. What lives on Codeforces stays on Codeforces — this site has no way to change anything there.

This is a personal project by one person, and it is honest rather than lawyerly. If something here is unclear, ask in the same place and the page gets clearer.
